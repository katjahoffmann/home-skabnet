## About

This app was developed for the open source [Home Assistant](https://www.home-assistant.io) project, more specifically for the Home Assistant OS. It's goal is to provide user with a possibility to provide data streams from within their Home Assistant to others in the community. The app uses the [SkABNet](https://ieeexplore.ieee.org/document/10230169) protocol to enable users to link themselves to others, creating a complex network ring. This ring can then be searched for specific data streams, eliminating the need for a central service/database to provide a list of providers.
